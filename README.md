# X-Burguer Entregas

Sistema web responsivo para controle de entregas da X-Burguer.

## Funcionalidades

- Login local
- Dashboard operacional
- Cadastro, edição e acompanhamento de entregas
- Cadastro e gestão de entregadores
- Fechamento diário
- Relatórios e ranking
- Exportação CSV
- Backup e restauração em JSON
- Persistência no navegador com localStorage
